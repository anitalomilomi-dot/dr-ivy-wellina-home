如何成為芳療師？先看清楚學習目標與路徑

不同課程與機構的培訓目標、時數、評量及證書關係可能不同，先從自己想投入的方向開始比較。

與其先問哪一張證書最好，不如先確認自己希望累積生活應用、專業知識、教學能力，或跨專業工作的哪一部分。

01

定義自己的角色方向

先區分興趣學習、專業進修、講師培訓或國際認證。不同目標需要的課程深度與實作累積不同。

02

比較完整課程資訊

查看先備條件、內容、時數、講師、評量、教材、實作與課後支持，不只看課程名稱。

03

核對證書與發證關係

若涉及國際單位，應從官方來源確認正式名稱、適用範圍、學校關係與目前有效狀態。

QUESTIONS TO ASK

在選擇之前，
先問自己這幾題。

  1. 01我想把芳香知識用在哪個工作或生活場景？
  2. 02我需要的是單次體驗、完整培訓，還是講師能力？
  3. 03課程的評量與實作方式是否寫清楚？
  4. 04認證關係能否在官方來源查到？
