精油擴香入門：從空間、設備與紀錄開始

擴香不是只挑一個喜歡的味道，也要一起考慮空間大小、設備說明、使用者與環境條件。

先把擴香當成一項可以觀察與調整的氣味練習。從單方、短時間與清楚紀錄開始，更容易知道自己真正喜歡什麼。

01

先看空間與使用者

確認空間是否通風、有哪些人或動物共同使用，以及設備放置位置；有特殊需求時先向合格專業人員詢問。

02

依設備說明操作

不同擴香設備的容量、清潔方式與操作時間不同，優先依產品與設備原廠說明，不自行套用固定數字。

03

建立擴香紀錄

記下使用的精油、空間、時間、第一印象與後續感受。累積幾次之後，就能比較出自己的偏好。

QUESTIONS TO ASK

在選擇之前，
先問自己這幾題。

  1. 01這個空間有哪些人會一起使用？
  2. 02設備原廠的使用與清潔方式是什麼？
  3. 03我能否先以單一香氣建立基準？
  4. 04使用後是否有任何不舒服，需要立即停止？
