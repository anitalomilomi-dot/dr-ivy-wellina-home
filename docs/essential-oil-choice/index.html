首頁/知識資源/學習指南

精油怎麼選？先從用途與標籤開始

第一次選精油時，先釐清學習目的，再閱讀植物學名、萃取部位、來源與產品說明，會比只看商品名稱更清楚。

這是一張選擇地圖，不替任何人指定單一答案。先知道自己要嗅聞、擴香、調香，或進一步學習，再回到可核對的產品資料。

01

先寫下使用目的

把需求寫成具體情境，例如認識單方香氣、練習擴香、學習調香，或準備進入系統課程。

  • 避免只用模糊的效果詞挑選
  • 一次先設定一個學習目標
  • 特殊情況先詢問合格專業人員
02

讀懂產品標籤

至少查看植物學名、植物部位、萃取方式、產地或來源、批次與使用說明；資料不完整時先保留疑問。

  • 中文俗名相同，不代表植物一定相同
  • 以完整標示協助辨識
  • 保留購買來源與批次資料
03

先單方、再比較

初學時可以一次觀察一種香氣，記下第一印象、前後變化與個人聯想，再進入兩種以上的比較。

  • 使用聞香紙或課堂指定方式
  • 記錄時間與香氣變化
  • 嗅覺感受沒有唯一標準答案

QUESTIONS TO ASK

在選擇之前，
先問自己這幾題。

  1. 01我想學的是日常使用，還是專業調香？
  2. 02我能否從標籤找到完整植物學名？
  3. 03產品是否提供清楚的保存與使用說明？
  4. 04我是否需要老師帶領安全觀念與實作流程？
