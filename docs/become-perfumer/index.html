如何成為調香師？從嗅覺訓練到作品紀錄

調香學習可以從氣味詞彙、原料辨識、配方紀錄與作品整理逐步累積，再依目標選擇生活、品牌或專業路徑。

調香不是只靠靈感。能穩定描述、重複記錄與回頭修正，才能讓一個氣味想法逐漸成為可溝通的作品。

01

練習嗅聞與描述

建立自己的香氣詞彙，同時學會使用共通分類與原料名稱，讓感受可以被記錄與討論。

02

累積原料與配方紀錄

每次練習保留日期、原料、比例、嗅聞變化與修改理由，逐步形成可回顧的學習檔案。

03

形成作品與方向

依興趣選擇個人香氣、活動體驗、品牌氣味或更完整的專業訓練，再補足相應知識。

QUESTIONS TO ASK

在選擇之前，
先問自己這幾題。

  1. 01我是否願意持續做嗅聞紀錄？
  2. 02我想創作個人香氣，還是處理品牌需求？
  3. 03課程是否包含原料辨識、實作與作品回饋？
  4. 04完成後能留下哪些可回顧的作品資料？
