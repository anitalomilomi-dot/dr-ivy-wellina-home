精油香水與調香入門：先學會描述香氣

調香的第一步不是急著追求完成品，而是建立嗅聞、描述、比較與記錄香氣的能力。

一張聞香紙、一份嗅聞紀錄，就能成為調香學習的開始。先建立自己的香氣語言，再理解原料如何彼此呼應。

01

建立香氣詞彙

用花香、草本、木質、清新、甜潤等方向記錄第一印象，也可以寫下顏色、畫面與記憶。

02

比較前後變化

同一香氣在不同時間可能呈現不同感受。記下嗅聞時間與變化，比只寫喜歡或不喜歡更有用。

03

從小型練習累積

先練習兩到三種原料的關係，再逐步增加複雜度；所有比例、基底與使用方式以課程帶領及材料說明為準。

QUESTIONS TO ASK

在選擇之前，
先問自己這幾題。

  1. 01我能否用三個詞描述這個香氣？
  2. 02它讓我想到什麼顏色、材質或畫面？
  3. 03經過一段時間後，哪些部分改變了？
  4. 04我想走生活體驗、品牌香氣，還是專業調香路徑？
