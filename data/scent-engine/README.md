# 香氣測驗後台資料

此資料夾只供 Dr. IVY × WELLINA 內部使用，不得輸出到消費者頁面。

## 已落地的結構

- 15個香調，每類固定8款精油、2款調香單體。
- 每類保留A／B兩個配方編號，共30個配方槽位。
- 測驗只能選擇既有香調與配方編號，不得臨時自由生成第31個配方。
- `S09-A` 是「靜謐木香調」內部試香代表配方，用來驗證滴定、版本、成本與安全流程；尚未獲准製作給消費者。
- `inventory-candidates.v1.json` 保存Ivy新增的可選精油／芳香素材；中文名稱不夠精確的原料會被系統鎖定，補齊瓶身學名、萃取型態與供應商文件後才可選入正式配方。

## 配方成為可製作版本的必要欄位

1. 原料正式名稱、來源、供應商、批號、COA與SDS。
2. 原液／預稀釋濃度、Ivy滴定滴數、加入順序與母配方總滴數。
3. 滴數／mL校正、密度、重量百分比與批次換算。
4. 5mL、3%成品換算、基底與實際用途。
5. IFRA適用類別、限制、安全與標示審核。
6. 原料、瓶器、標籤、包材、人工、金流與寄送成本。
7. 試香紀錄、Ivy修訂、版本、核准日期與製作批次。

只有狀態為 `ivy_approved` 的配方，後台程式才允許交給製作流程。
